## Ground rules for every step

- PR-sized, independently revertible with `git revert <merge-commit>`. No step mixes concerns.
- Validation baseline (every step): 
  `python -m pytest scripts/ tests/ -q --tb=short --ignore=scripts/test_collect_polls.py --ignore=scripts/test_index_to_vertex_search.py`
  (local env cannot install sklearn/playwright/google-cloud - OBSERVED; those paths MUST be validated by green CI on the PR).
  Site-touching steps add: `cd site && node node_modules/vite-react-ssg/bin/vite-react-ssg.js build && node scripts/postbuild-seo.mjs` (Termux-safe form of `npm run build`; CI uses npm form).
- Stop conditions (abort step, do not merge): any previously-passing test fails for non-obvious reasons; diff shows unrelated file changes; a contract test must be weakened to pass; CI red on blocked-subset paths.
- Evidence threshold column states what justifies the step. Steps without met thresholds are gated and must not start.

## Sequencing rationale

M0 is outage-class and goes alone/immediately. M1 unlocks everything path-related. M2 makes relocation steps honest (whitelist diffs become review artifacts). M3->M5 shrink public surface before adding M6's CI churn. M6 precedes M7 because ownership decisions are safer once sync machinery is single-sourced. M8 after M4 settles final path. M9 independent filler. M10 explicitly evidence-gated.

Total: 10 steps (~13 small PRs). No step requires coordinated downtime; site keeps building throughout except during M0 window which *fixes* builds.

## Explicitly out of scope (this plan)

Schema hard-blocking decision (R7), AI provider chain redesign, frontend framework/i18n changes, Option B/C upgrades (thresholds in 03 §6).
